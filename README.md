# AI 의존도 조사 → 생일 축하

학교·이름 입력 → 생일 축하 → 선물 선택 → 이메일 전송 접수.

## 이메일 연결 (필수)

config.js에 Formspree 폼 https://formspree.io/f/xnpnpzbb 가 연결되어 있습니다. 수신 이메일은 Formspree에서 관리합니다.

1. https://formspree.io 에 가입하고 받을 이메일을 확인합니다.
2. 폼을 만들고 Integration에 있는 https://formspree.io/f/... 주소를 복사합니다.
3. config.js의 formEndpoint에 그 주소를 넣습니다. 비밀번호나 비밀 API 키는 넣지 마세요.
4. 실제 사이트에서 테스트 정보를 제출하고 Formspree 접수 내역과 이메일 수신을 모두 확인합니다.

학교, 이름, 선물은 마지막 전송 버튼을 눌렀을 때만 Formspree로 보내며 수신 이메일로 전달됩니다. 서비스의 요금제 한도 및 스팸 설정이 적용됩니다.

접수 성공 응답 이후에만 완료 화면을 표시합니다. 전송 중 연속 클릭을 막고, 실패하면 선택을 보존합니다. 네트워크 오류나 시간 초과는 접수 여부가 불명확할 수 있어 중복 전송 가능성을 안내합니다. 이 페이지에서 전송 성공 후 다시 전송할 수는 없지만 새로고침 후 재제출까지 차단하지는 않습니다.

## GitHub Pages 배포

폴더 안 파일 전체를 저장소 최상위에 올린 뒤 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다. config.js도 포함해야 합니다. 설치나 빌드는 필요 없습니다.

리다이렉트 대상에는 배포 주소를 넣으세요. 하나의 주소로 여러 명이 사용합니다.



## 배경음악
사용자가 제공한 birthday.mp3를 축하 화면으로 넘어갈 때 재생합니다. 선물 선택 중에도 이어지며 한 곡이 끝나면 멈춥니다. 상단 버튼으로 일시정지 및 다시 재생할 수 있습니다. 자동 재생이 제한되면 노래 듣기 버튼을 누릅니다. 배포 시 MP3도 함께 업로드해야 합니다. YouTube 연결은 사용하지 않습니다.
